\## How to Contribute



1\. \*\*Fork the Repository\*\*: Click the "Fork" button on the \[MetroStack GitHub page](https://github.com/pmay519/MetroStack) to create your copy.

2\. \*\*Clone Your Fork\*\*: `git clone https://github.com/your-username/MetroStack.git`

3\. \*\*Create a Branch\*\*: `git checkout -b feature/your-feature-name`

4\. \*\*Make Changes\*\*: Implement your changes following the \[Code Style Guidelines](#code-style-guidelines).

5\. \*\*Commit and Push\*\*: Commit your changes and push them to your fork.

6\. \*\*Submit a Pull Request\*\*: Go to the MetroStack repository and click "New Pull Request" to submit your changes for review.



\## Code Style Guidelines



\- \*\*Python\*\*: Follow \[PEP 8](https://www.python.org/dev/peps/pep-0008/) conventions.

\- \*\*TypeScript/JavaScript\*\*: Use consistent naming, avoid global variables, and follow common best practices.

\- \*\*General\*\*: Write clear, commented, and documented code. Include docstrings and type hints where applicable.



\## Reporting Issues



When reporting bugs or issues, please include:



\- Operating system and version.

\- Software versions (Python, Node.js, PostgreSQL).

\- Steps to reproduce the issue.

\- Any relevant error messages or screenshots.



Search existing issues before creating a new one. Use the \[GitHub Issues](https://github.com/pmay519/MetroStack/issues) tab to submit.



\## Pull Request Guidelines



\- \*\*Title\*\*: Use a clear, descriptive title.

\- \*\*Description\*\*: Explain the purpose and changes made.

\- \*\*Review Process\*\*: Maintainers will review PRs within \[X] days. You may be asked to make changes or provide additional information.



\## Code of Conduct



We follow the \[Contributor Covenant Code of Conduct](https://www.contributor-covenant.org/version/1/4/code-of-conduct.html). All participants are expected to uphold these standards to ensure a welcoming and respectful community.



\## Development Setup



\- Install Python 3.x and Node.js.

\- Clone the repository and run `pip install -r requirements.txt` for Python dependencies.

\- For frontend, run `npm install` to install JavaScript dependencies.

\- Configure PostgreSQL database as per the project documentation.
